# CSE1106-2

## Description

Simply tic tac toe slop game. There are no fancy visuals or intersting game mechanics. The game is as bare bones as tic tac toe can be

## How to Run

There is no executable for this project, so it's going to require a debugger. Have any version of a python compiler and simply run the game. 

## What I Learned

I learned what steps are needed in order to upload code to a GitHub repository. 

The most critical thing I learned is reuploading SSH keys. Sometimes, the keys will mismatch between your machine and the Git server.
So, the solution is to simply create a new key and reconnect them. After that, upload your code and it should work. 

## Future Improvements

There will not be any future improvements to the game. This was just an attempt at creating and uploading my own GitHub repository.
